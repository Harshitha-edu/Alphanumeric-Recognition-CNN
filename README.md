# Alphanumeric-Recognition-CNN

Alphanumeric character recognition using Convolutional Neural Networks (CNN) with Python, TensorFlow and Keras.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Scikit-learn
- Tkinter
- Matplotlib
- Seaborn

## Key Features

- Alphanumeric character recognition
- Image preprocessing
- RGB and grayscale image conversion
- Green-pixel removal
- Histogram-based feature extraction
- GLCM-based feature extraction
- CNN-based classification
- Model loading using JSON architecture and H5 weights
- Accuracy, Precision, Recall and F1-score evaluation
- Confusion matrix
- Tkinter-based graphical user interface

## Project Structure

- `Main.py` – Main Python application
- `requirements.txt` – Required Python libraries
- `character_recognition_results.docx` – Project results
- `model/` – Trained model files
- `Dataset/` – Dataset
- `testimages/` – Test images

## Objective

The objective of this project is to develop an automated system for recognizing alphanumeric characters from images using image processing techniques and a CNN-based deep learning approach.
